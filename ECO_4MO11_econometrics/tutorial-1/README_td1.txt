Tutorial 1 - Introductory Econometrics

Files provided
--------------
- exercises.pdf: exercise and lab questions.
- code/lab1.py: Python file to complete during the tutorial.
- data/wage1.csv: dataset used in Lab 2.

Keep the extracted folder organised as follows:

Tutorial_1/
|-- exercises.pdf
|-- README_td1.txt
|-- code/
|   |-- lab1.py
|   `-- output/        (created automatically when the script runs)
`-- data/
    `-- wage1.csv

Before the tutorial
-------------------
1. Install Python 3.
2. Install the required packages:

   pip install numpy pandas matplotlib statsmodels

3. Extract the complete ZIP, keeping the code and data folders together.
4. Open code/lab1.py.

No paths need to be edited. The script finds data/wage1.csv relative to its
own location and creates code/output/ for figures and tables.
